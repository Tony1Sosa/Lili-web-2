# Строителна Компания БГ — уебсайт

Статичен сайт (HTML / CSS / JavaScript) с една малка PHP част (форма за контакт и
админ панел за обяви). Без build стъпка — файловете се качват директно на хостинга
през FileZilla → cPanel.

- **Палитра:** „Теракота / Terracotta Atelier“ · **Шрифтове:** Lora + Mulish
- **Езика на сайта:** български
- **Development / preview:** GitHub + GitHub Pages
- **Production:** SuperHosting.bg + финален домейн (вж. `DEPLOYMENT.md`)

> ⚠️ Логото, снимките и някои данни са **временни заместители**. Вижте раздел
> „Какво още трябва да се направи“ по-долу и `assets/brand/README.md`.

## Редакция на съдържание

- **Текст/снимки:** редактирайте директно съответния `.html` файл. Блоковете
  `<!-- ==== HEADER ==== -->` и `<!-- ==== FOOTER ==== -->` са еднакви на всички
  страници — при промяна на менюто ги синхронизирайте навсякъде.
- **Цветове/шрифтове:** сменят се на едно място — променливите в началото на
  `css/styles.css` (`:root { --accent: … }`). Целият сайт се пребоядисва.
- **Снимки:** навсякъде, където виждате пунктирана рамка с надпис „Снимка: …“,
  има място за реална снимка. Заменете `<div class="ph …">` с
  `<img src="assets/img/вашата-снимка.jpg" alt="описание">`.
- **Лого:** заменете файловете в `assets/brand/` (вж. тамошния README) — без
  промяна по кода.
- **Обяви (Директни продажби):** управляват се през админ панела (вж. `DEPLOYMENT.md`).

## Локален преглед

Отворете файл през локален сървър (не само двоен клик), за да заредят обявите:

```
php -S localhost:8000      # дава и PHP (форма + админ панел)
# или:  python3 -m http.server 8000   (без PHP)
```
После: <http://localhost:8000/>

## GitHub Pages (preview) ↔ SuperHosting.bg (production) — разлики

| Тема | GitHub Pages (преглед) | SuperHosting.bg (production) |
|------|------------------------|------------------------------|
| Пътища | сервира от под-папка `/<repo>/` | сервира от корена на домейна |
| Форма за контакт | няма PHP — формата показва резервно съобщение | PHP `api/contact.php` праща имейл |
| Админ панел | не работи (няма PHP) | работи (PHP + сесия) |
| `.htaccess` | игнорира се | активен (HTTPS, 404, кеш) |
| Домейн/SSL | авт. `*.github.io` | личен домейн + Let's Encrypt |

Всички пътища в сайта са **относителни** (`css/styles.css`, `za-nas.html`), затова
работят и в двете среди без твърдо кодиран GitHub Pages адрес.

## Какво още трябва да се направи (съдържание за потвърждение)

- [ ] **Реални снимки** от обекти/екип (вкл. Нюрбургринг и архивни от 90-те/2000-те).
- [ ] **Потвърждение на адреса на офиса** — в материалите има две версии (ул. Осогово №81 срещу жк. Люлин 8). На сайта е заложена версията от структурния документ; да се потвърди.
- [ ] **Точните числа** за статистиките (години, брой обекти, държави).
- [ ] **Съгласие на клиентите** за публикуване на лого/име (засега са показани само имена).
- [ ] **Railing-Inox** — потвърждаване на партньорските твърдения и връзка към railing-inox.com.
- [ ] **Финален домейн** — да се обнови в `sitemap.xml`, `robots.txt`, JSON-LD,
      `og:url` / `og:image` (във всички `.html`) и `$FROM_ADDR` в `api/contact.php`.
